# MeusContatos

Aplicativo Android desenvolvido em Java e XML como projeto acadêmico.

## Sobre o projeto

O MeusContatos é um aplicativo de agenda pessoal que permite cadastrar e organizar contatos diretamente pelo celular.

## Funcionalidades

- Cadastro de contatos
- Listagem de contatos
- Pesquisa de contatos
- Visualização dos detalhes
- Edição de contatos
- Exclusão de contatos
- Armazenamento local utilizando SQLite

## Tecnologias utilizadas

- Java
- XML
- Android SDK
- SQLite
- Gradle

## Estrutura do projeto

- MainActivity.java: lógica principal do aplicativo.
- ContatoAdapter.java: exibição dos contatos.
- DatabaseHelper.java: gerenciamento do banco SQLite.
- activity_main.xml: layout da tela principal.
- item_contato.xml: layout de cada contato.

## Como executar

1. Clone este repositório.
2. Abra o projeto em um ambiente compatível com Android e Gradle.
3. Aguarde a configuração do Gradle.
4. Execute em um dispositivo Android ou emulador.

Para compilar no Windows:

    .\gradlew.bat assembleDebug
